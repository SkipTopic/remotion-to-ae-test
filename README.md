# Remotion 转 AE 测试

把一个用 **Remotion（React 网页动画）** 做的 13 分半科普动画，
完整转换成 **After Effects 可编辑工程**的实测记录。

**核心结果：814 秒 / 62 个场景 / 4267 个图层，全部是 AE 形状层和文本层，一张位图都没有。**

## 怎么打开

1. 装 **After Effects 2024**（24.x 或更新）。
2. **把整个仓库克隆/下载下来**，不要只拿 `.aep` 单文件——它引用 `audio/master.m4a`。
3. 双击 `癫痫科普_MG_AE工程_v2.aep`。
4. 首次打开如果提示缺少字体，装一下 **微软雅黑** 和 **宋体**（Windows 自带）即可。

### 工程结构

```
00_MAIN        814.773 秒，1 个音频层 + 10 个章
01_CHAPTERS    Ch00 ~ Ch09
02_SCENES      62 个场景（Ch00_S01 … Ch09_S05）
```

双击任意场景（比如 `Ch06_S07` 药盒周表），里面是几十个独立图层：

- `*_rect_*` → **形状层**，双击改填充色、改圆角、拉尺寸
- `*_text_*` → **文本层**，双击直接改字，自动重排
- `*_svg_*`  → **形状层**（矢量路径），从网页 SVG 转过来的，比如脑网络图、人物线稿

## 为什么要做这件事

Remotion 是"用 React 写视频"的工具，做 MG 动画很爽（组件化、时间轴即代码），
但**甲方要改一个字就得改代码重新渲染**，这在很多工作流里是死结。

常见的"转换"做法是**逐帧烘焙成 PNG 再叠时间轴**——那不是转换，那是截图。
结果是几十上百 MB 的位图、改不了一个字、拖不动一个色块。

这个测试验证了另一条路：**把 DOM 拆成几何 + 样式 + 矢量路径，在 AE 里用原生形状层重建**。

| | 位图烘焙方案 | 本方案 |
|---|---|---|
| 素材 | 1104 个元素全变 PNG（54 MB），大量 1920×1080 全屏图 | **0 张 PNG** |
| 图层类型 | Footage（位图） | Shape / Text |
| 文字 | 图片，改不了 | 双击就能改 |
| 颜色 | 图片，改不了 | 每个色块独立可改 |
| 体积 | 工程 30 MB + 素材 54 MB | **67.9 MB（含音频）** |
| 后期可改性 | 基本为零 | 和时间轴原生工程一样 |

## 技术上怎么做到的（简述）

完整版见 [`docs/制作方法.md`](docs/制作方法.md)。

1. **在浏览器里跑 Remotion Player**，逐帧 `seekTo`。
2. **遍历 DOM**，把每个可见元素拆成"几何 + 样式 + 矢量路径"：
   - 普通 div → 圆角矩形 / 椭圆（bbox + border-radius + 填充 + 描边）
   - `<svg>` → 解析所有 `<path>` 的 `d`，转成三次贝塞尔顶点（自己写了 path parser，因为 Chrome 的 `getPathData()` 在这台机器上不存在）
   - 文字 → 用 `Range.getBoundingClientRect()` 量真实文字边界（不能用元素框，左对齐会偏）
3. **每 2 帧采样一次**，用阈值法抽稀成关键帧（位置 0.6px / 尺寸 0.8px / 透明度 2%）。
4. **生成 ExtendScript**，在 AE 里用 `addShape()` / `addText()` 重建，打关键帧。
5. `AfterFX.exe -r script.jsx` 一次性执行，53 分 24 秒建完 4267 层，0 错误。

### 几个关键坑（都写在 docs 里了）

- 混合文本块：`<Title>很多年后，<br/>我打开了一台<br/><span>旧电脑</span></Title>`
  前两行是**纯文本节点、没有对应元素**，直接遍历 DOM 会漏掉，只剩 span 里的字。
- 图层入点必须**归一化到场景内**，用章内绝对帧号会让整场推到最后全黑。
- `td.tracking` 只接受整数，传小数会让整个脚本中止。
- 微软雅黑的字体名要写 `Microsoft YaHei`（带空格）。
- `saveFrameToPng` 对含预合成的合成不可靠，截图会全黑（但工程本身没问题）。

## 已知问题

1. **章节合成直接截图是黑的**——`saveFrameToPng` 对含预合成的 comp 不可靠。
   在 AE 里正常预览/播放没问题，要出图请用渲染队列。
2. **个别长文本会左右溢出**——中文换行位置和网页渲染不同。
3. **旋转关键帧没接**——目前只做了位置/尺寸/透明度。
4. `scripts/` 里的脚本是**从实际项目里摘出来的**，直接跑需要 Remotion 源码工程
   （本仓库不含原版 Remotion 工程，按作者要求）。脚本主要作为**实现参考**。
