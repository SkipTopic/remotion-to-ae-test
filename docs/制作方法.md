# 制作方法：从 Remotion 到 AE 原生工程

> 这份文档记录把 814 秒的 Remotion 动画转成 AE 可编辑工程的完整做法。
> 所有数字都是实测值，不是估算。

---

## 0. 一句话总结

**在浏览器里逐帧跑 Remotion，把每帧的 DOM 拆成"几何 + 样式 + 矢量路径"，
再在 AE 里用原生形状层和文本层重建，打关键帧。**

不是截图，不是拆帧，是**结构化重建**。

## 2. 五步管线

```
① 打包播放器       esbuild 把 Remotion Player 打成一个 bundle.js
② 逐帧采样         Playwright 打开页面，seekTo(f) 后注入提取器
③ 数据归一化       帧号转场景内、文本按内容分轨、去重叠字幕
④ 生成 ExtendScript 每个元素 → 一个形状层或文本层 + 关键帧
⑤ AE 执行          AfterFX -r，一次性建完全片
```

### ① 打包播放器

Remotion 的组件必须在 React 环境里跑，所以做一个最小的播放页：

```jsx
createRoot(document.getElementById('root')).render(
  <Player ref={ref} component={Comp} durationInFrames={DUR}
          fps={30} compositionWidth={1920} compositionHeight={1080}
          controls={false} style={{width:1920, height:1080}} />
);
window.__seek = async (f) => {
  ref.current.seekTo(f);
  await new Promise(r => requestAnimationFrame(() => requestAnimationFrame(r)));
  await new Promise(r => setTimeout(r, 40));   // 等字体/布局稳定
};
```

用 esbuild 打成 IIFE，起个本地 http server 就能访问。

### ② 逐帧采样

每 2 帧取一次（15fps 采样），814 秒 × 30fps ÷ 2 ≈ 12000 次。

每次 `seekTo` 后调用注入的 `__extract()`，返回该帧所有可见元素的数组。

### ③ 数据归一化

- **帧号转场景内**：`f - scene.fromF`（这一步不做会导致整场全黑，见 §6.1）
- **文本按内容分轨**：签名 = `path + '#' + 完整文本`，字幕逐句切换才能分成不同轨道
- **去重叠字幕**：同一位置"整句 + 当前句"两层叠着，保留较短那句

### ④ 生成 ExtendScript

每个元素生成一段 AE 脚本：

```js
try {
  var ly = sc.layers.addShape();
  ly.name = "Ch06_S07_e012_rect_380x86";
  // …建矩形、填充、描边…
  _p.setValueAtTime(0, [960, 540]);     // 位置关键帧
  _o.setValueAtTime(0, 100);            // 透明度关键帧
  ly.inPoint = 0; ly.outPoint = 12.9;
} catch(e) { _errs.push("e012: " + e.message); }
```

**每层独立 try/catch** —— 单个元素出错不能拖垮整片。

### ⑤ AE 执行

```bash
AfterFX.exe -r 癫痫科普_MG_AE工程_v2.jsx
```

脚本里自己 `app.quit()` 收尾。7.9 MB 的脚本，53 分 24 秒建完 4267 层，0 错误。

## 3. 提取器：怎么把一个 DOM 变成 AE 层

### 3.1 元素分类

遍历 DOM，每个元素先判断"能不能单独成层"：

| 判断 | 产出 |
|---|---|
| 无子元素 + 有文字 | **文本层** |
| 子元素全是 inline（br/span）+ 自身有文本节点 | **富文本块**（整块一个文本层） |
| `tag === 'svg'` | **矢量形状层**（内部按填充色分组） |
| 无子元素 + 有背景/边框 | **形状层**（圆角矩形） |
| 有子元素 + 有背景 | **底板形状层** + 继续下钻 |

### 3.2 坐标：全部换成屏幕坐标

SVG 内部的路径点用 `getScreenCTM()` 变换到屏幕坐标：

```js
const V = (x, y) => [m.a*x + m.c*y + m.e - R.x, m.b*x + m.d*y + m.f - R.y];  // 顶点：含平移
const T = (x, y) => [m.a*x + m.c*y,           m.b*x + m.d*y];                // 切线：只做线性
```

**切线是向量，不能加平移**——加了会整个变形。

### 3.3 文字：必须用 Range 量

```js
const r = document.createRange();
r.selectNodeContents(el);
const b = r.getBoundingClientRect();   // 真实文字边界
```

用 `el.getBoundingClientRect()` 会拿到**容器**宽度（比如 880px），
但实际文字只有 200px 宽，在 AE 里按容器居中就会整体右偏。

### 3.4 富文本块：这是最容易漏的地方

```jsx
<Title>
  很多年后，<br/>
  我打开了一台<br/>
  <Highlight>旧电脑</Highlight>
</Title>
```

前两行是**纯文本节点，没有对应元素**。只遍历 `el.children` 的话，
只能抓到 `<span>` 里的"旧电脑"，前面两行整段丢失。

正确做法：检测"子元素全是 inline + 自身直接挂着文本节点"，
然后用递归拼 `<br>` → `\n`：

```js
function extractText(el) {
  let s = '';
  const rec = (n) => {
    if (n.nodeType === 3) { s += n.textContent; return; }
    if (n.tagName === 'BR') { s += '\n'; return; }
    for (const c of n.childNodes) rec(c);
  };
  for (const c of el.childNodes) rec(c);
  return s.replace(/[ \t]+/g, ' ').trim();
}
```

### 3.5 SVG 路径：自己写 parser

Chrome 的 `SVGPathElement.getPathData()` 在这台机器的版本上**不存在**，
只能读 `d` 属性自己解析。

`pathparse.js` 支持全部命令：`M L H V C S Q T A Z`，绝对/相对都行。
关键是**圆弧 A 要转三次贝塞尔**：

```js
// SVG 规范 F.6.5：端点参数 → 中心参数，再按 ≤90° 分段
const nSeg = Math.max(1, Math.ceil(Math.abs(dth) / (Math.PI / 2)));
const t = (4/3) * Math.tan(delta/4);
```

输出结构直接对应 AE 的 `Shape`：

```js
{ v: [[x,y],…], i: [[inx,iny],…], o: [[outx,outy],…], c: closed }
```

- `v` = 顶点
- `i` = 进入切线（相对顶点的向量）
- `o` = 离开切线
- 连续三次贝塞尔拼接时，前一点的 `o = c1 - prev`，当前点的 `i = c2 - p`

### 3.6 层级顺序：seq 必须严格递增

AE 的 `layers.add()` 把新层插在**最上面**。
所以按 DOM 顺序**正序**创建，先建的在下——正好对应 DOM 的绘制顺序。

`seq` 要在每个元素入数组时 `seq++`，包括文本层自己的背景层（bg 先 push，文本后 push）。

## 4. 关键帧抽稀

15fps 采样 → 每属性最多 40 个关键帧。

**阈值法**（不是 Douglas-Peucker——那个在"值空间"算距离会忽略时间轴，把"快速淡入然后停住"的拐点全丢掉）：

```js
let last = pts[0].v;
for (const p of pts) {
  const diff = Array.isArray(p.v)
    ? Math.max(Math.abs(p.v[0]-last[0]), Math.abs(p.v[1]-last[1]))
    : Math.abs(p.v - last);
  if (diff > tol) { out.push(p); last = p.v; }
}
```

阈值：位置 0.6px / 尺寸 0.8px / 透明度 2%。

**必须设 LINEAR 插值**，AE 默认的 bezier 会让匀速运动变成"快-慢-快"。

## 5. 在 AE 里建层

### 5.1 形状层

```js
var ly = sc.layers.addShape();
var g  = ly.property("ADBE Root Vectors Group").addProperty("ADBE Vector Group");
var vg = g.property("ADBE Vectors Group");
var rc = vg.addProperty("ADBE Vector Shape - Rect");
rc.property("ADBE Vector Rect Size").setValue([w, h]);
rc.property("ADBE Vector Rect Roundness").setValue(radius);
var fl = vg.addProperty("ADBE Vector Graphic - Fill");
fl.property("ADBE Vector Fill Color").setValue([r/255, g/255, b/255]);
```

### 5.2 文本层

```js
var P = ly.property("Source Text");
var td = P.value;
td.font = "Microsoft YaHei";     // ← 必须带空格
td.fontSize = 38;
td.applyFill = true;             // ← 必须在 fillColor 之前
td.fillColor = [0.11, 0.17, 0.23];
td.tracking = Math.round(letterSpacing / fontSize * 1000);  // ← 必须是整数
P.setValue(td);
```

### 5.3 尺寸变化用 Scale，不要用 Rect Size 打关键帧

`ADBE Vector Rect Size` 直接 `setValueAtTime` 在 24.1 中文版上会报"对象无效"。
改成 Scale 关键帧（以首帧尺寸为 100%）就行，纯填充图形不会有描边变形问题。

## 6. 两个致命 bug（都踩过）

### 6.1 全片全黑：帧号没归一化

**现象**：构建日志 `errors=0`、4267 层全部建成，但抽查发现**除了每章第一个场景，其他全黑**。

**原因**：图层入点用了章内绝对帧号。

```js
// 错的
const inT = tr.samples[0].f / FPS;   // Ch06_S07 的 fromF = 1846 → inPoint = 61.5s
```

而 `Ch06_S07` 这个合成只有 12.9 秒长，所有层都被推到 61.5 秒之后。

**为什么第一章看不出来**：Ch00 的 `fromF = 0`，减不减都一样。

**修复**：

```js
const _frames = d.frames.map(fr => ({f: fr.f - d.fromF, els: fr.els}));
let tracks = buildTracks(_frames);
```

**教训**：`errors=0` 不代表画面对。必须抽非第一章的场景渲染验证。

### 6.2 章节合成截图全黑（但工程是好的）

`saveFrameToPng` 对**含预合成层**的合成不可靠——预合成要先被渲染过才有像素缓存，
直接截图拿到的是空的。

**这不是工程问题**。AE 里正常预览/播放没问题，要出图请走渲染队列。
验证质量请截**场景合成**（无预合成），那个可靠。

## 7. 其他踩过的坑

| 坑 | 现象 | 解法 |
|---|---|---|
| `td.tracking` 传小数 | 整个脚本中止，一层都建不成 | `Math.round()` |
| 字体名 `MicrosoftYaHei` | 文本层属性读取报"除以零" | 写 `Microsoft YaHei` |
| 中文文件名写出失败 | `saveFrameToPng` 返回 true 但文件不存在 | 素材名全 ASCII |
| `saveFrameToPng` 前没 `openInViewer` | 返回 true，写出 0 字节 | 先 `comp.openInViewer()` |
| 连续写多张 PNG | 只有第一张落盘 | 每张后 `$.sleep(700)` |
| SVG 父容器吞掉整棵子树 | 大量元素丢失 | 只对 `tag === 'svg'` 生效，不要 `querySelector('svg')` |
| 基线版用 `getPathData()` | 本机 Chrome 无此 API | 自己写 path parser |

## 9. 想复现的话

`scripts/` 里的脚本是**从实际项目里摘出来的**，需要配合 Remotion 源码工程使用
（本仓库按作者要求不含原版 Remotion 工程）。

大致流程：

```bash
# 1. 把 scripts/ 里的 entry 页面放进 Remotion 工程，esbuild 打包
./node_modules/.bin/esbuild tools/ae_probe/entry.jsx --bundle \
  --outfile=tools/ae_probe/bundle.js --loader:.tsx=tsx --jsx=automatic \
  --define:process.env.NODE_ENV='"production"' --format=iife --platform=browser

# 2. 起本地服务
python -m http.server 8899 --bind 127.0.0.1

# 3. 采样（每章一次）
node sample.cjs Ch06 0 2

# 4. 生成 ExtendScript + 执行
node build_all.mjs out.aep
AfterFX.exe -r out.jsx
```

`run_ae.py` 负责启动 AE、自动关掉"崩溃修复选项"对话框、等进程退出。
